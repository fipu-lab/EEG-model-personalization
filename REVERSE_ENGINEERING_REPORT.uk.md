# REVERSE_ENGINEERING_REPORT — EEG-model-personalization

## A. Загальний діагноз

### Виявлена архітектура
Проєкт машинного навчання для персоналізації моделей EEG (електроенцефалограма). Архітектура:

- `models.py`: визначення моделей CNN 1D (CNN_1D_model, CNN_1D_BN_model, KAN_CNN_1D_model, KAN_CNN_1D_BN_model)
- `data_loader.py`: функції `read_data()` та `load_data()` для завантаження даних .npy та створення ковзних вікон
- `data_recorder.py`: скрипт для запису даних EEG через LSL (Lab Streaming Layer)
- `Personalization.ipynb`: ноутбук для індивідуального навчання, fine-tuning та transfer learning
- `Results.ipynb`: ноутбук для аналізу результатів (сумарна інформація, LaTeX, графік Pareto)
- `.gitmodules`: посилання на tfkan як субмодуль (https://github.com/ZPZhou-lab/tfkan/)
- `.gitignore`: стандартний шаблон Python + Jupyter

Довід: `data_loader.py:36-38` використовує `np.random.shuffle(ind)` без seed.
